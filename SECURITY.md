# Private operational data

Keep rosters, imported documents, source exports, event workspaces, rendered
booklets, screenshots, generated assets, and credentials outside source control.
Use synthetic participants in examples and tests. Review staged changes and run
the local roster-aware privacy check before every push, even to a private repo.

If data is accidentally uploaded, deleting it in a later commit does not remove
it from history. Stop further pushes and assess history, forks, artifacts, logs,
and any credential rotation needed before publishing again.
