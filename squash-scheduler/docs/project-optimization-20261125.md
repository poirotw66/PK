## 重跑

安裝鎖定 Python 與後台 Node 依賴後，使用 Python 3.13、Node 22 以上與可嵌入的中文字型：

```sh
squash-scheduler/.venv/bin/python scripts/verify_full_workflow.py \
  --font /path/to/licensed-cjk-font.ttf \
  --output squash-scheduler/output/verification/new-synthetic-run
```

輸出路徑必須是新資料夾。此指令建立合成賽事並使用隔離雲端 Worker，不會呼叫正式 Sites。
日常後台檢查由 `sites/squash-admin/scripts/verify-contracts.mjs` 執行；需先建立對應的後台及合成前台產物。
GitHub Actions 的 `Full synthetic tournament` 可手動執行完整 PDF 流程。

## 使用界線

備份是手動應用資料備份，並非自動平台災難復原；原始資料、地端工作區與正式文件仍需另存。
積分及特殊結果的條文不會由系統猜測；缺少規則時不會偽造排名。正式規則、排程可行性與主辦簽核仍須核定。
舊賽事須先核對來源及規則，才會開放相應特殊結果；不會為啟用功能清空現有資料。
