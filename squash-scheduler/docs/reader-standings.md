## 1. 循環積分表

閱讀頁新增「積分與排名」檢視，晉級圖表內也顯示各小組積分。欄位為選手、名次、積分、勝、敗、棄／退、勝局與負局。手機先呈現姓名、名次與積分，其餘欄位可在表格內左右捲動，姓名欄固定。

積分與名次直接沿用 `compute_rankings`，前端不另算一套。配分說明來自該組實際使用的規則，自訂勝敗配分或棄權規則不會被預設 2／1／0 蓋掉。公開資料只保留閱讀所需的數字與狀態，不帶出裁定原因、操作者或內部證據。

| 狀態 | 呈現 |
|---|---|
| 尚未完成 | 積分暫列；名次顯示破折號，不提前決定晉級 |
| 同分待裁定 | 顯示「同分待裁定」及「待核定」，不依姓名或資料順序編造名次 |
| 結果及排名已確認 | 顯示實際名次；有明訂小組晉級人數時，標示有效資格中的晉級者 |
| 人工名次核准後更正成績 | 重新核對裁定依據，舊核准失效時不繼續沿用 |

敗場包含判敗；棄／退是另外統計的次數，不能將兩欄直接相加當作已賽場數。棄權沒有虛構局分，實際出賽與計分場數也依規則分別保留。積分始終按完整小組計算，不隨搜尋、場地或日期篩選而重算局部名次。

人工排名裁定仍走既有審閱／CLI 核准流程，本輪沒有新增前端裁定表單。尚待核定時可先在閱讀頁確認狀態。

### 循環賽對戰圖上的即時賽果

「晉級圖表」中的循環階段，現在會先顯示各小組的多角形對戰圖，再顯示積分表。三人為三角形、四人為四角形、五人為五角形；僅繪製公開賽程中實際存在的對戰線，不依人數補造比賽。節點依對戰資料的固定順序排列，排名變動不會讓選手換位置。

成績預覽不填分；確認儲存後，每條線的兩端會顯示靠近該選手的勝局數，包含真實的 0 局。勝方使用青色數字。點選連線或比分，可展開場次、時間、場地及逐局比分；鍵盤也能聚焦連線並以 Enter／空白鍵開啟。成績更正後，開啟中的明細與線端比分一起更新。

棄權／未到場顯示「勝／棄」，雙方棄權為「棄／棄」，退賽為「勝／退」，特殊結果採虛線，沒有虛構 2:0 或 3:0。退賽末局可能尚未完成，因此不從領先的局分推算勝局；原始局分仍可在明細查看。未確認、已取消或排除的比賽不顯示比分。

手機保留可閱讀的圖形大小，可在圖內左右捲動；初次置中，後續同步保留捲動位置。圖表、卡片與積分表共用原有公開快照及輪詢，不讀取操作資料，也不新增寫入端點。沒有 `standings` 的舊版公開資料來源仍可閱讀既有逐場卡片。

可直接開啟 [已填分的獨立演練頁](http://127.0.0.1:8771/live/)，選「男子B組」查看五角圖、「男子C組」查看四角圖，或「男子D組」查看三角圖。這是使用真實姓名的獨立模擬複本，比分不代表正式賽果；既有完整名單工作區未被修改。

## 2. 特殊賽制連動

男子 F 虛構案例包含三個三人組、各組前二名及六位選手的現場抽位。小組排名完成只表示資格確認，不代表抽位已完成；須有執行紀錄、核准及啟用，閱讀頁才帶入抽位後的姓名。案例採小組第一抽 1／3／6 位置的明示虛構流程，**不代表歷史抽位執行或主辦已核准的正式賽程**。

鼓勵賽在國中組的資格及抽籤確認後出現；已驗證種子首輪敗者排除、三人籤表中的首輪輪空，以及核准前不發布提案。輪空姓名另行列出，沒有捏造一場比賽或比分。季軍賽則從準決賽的實際敗者取得對手；各階段的已確定選手保留來源場次或抽位說明。
