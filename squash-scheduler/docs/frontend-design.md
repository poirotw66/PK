# 賽事前端設計紀錄

本地賽務操作台沿用已選定的 Framed sheet（seed `20261028`），無重新抽選風格。以球場框線為識別，主要問題為「哪些場次需要登錄，哪些選手可進鼓勵賽」。資料以實際工作區計算；主操作包含種子設定、比分表單、資格原因及精確版本的確認預覽。匯出閱讀頁仍可離線，操作頁由本機服務寫入；新增的即時閱讀頁另由公開唯讀資料介面更新。

## 即時閱讀頁第一版

後續已加入循環積分與特殊賽制：積分表使用相同 Framed sheet、字體與中性表格，手機先呈現姓名、名次及積分，其他欄位在表內橫向捲動。未確認名次不填數字，人工核定前顯示待核定，確定小組晉級者才使用青色標示。循環賽對戰卡片收在可展開區域，自動更新保留展開狀態；原稿多邊形圖維持在既有文件，未佯稱已動態重繪。三階段的 33 個實際畫面在 `output/rf-final/`，積分頁官方 lint／inspect 為 0 FAIL／0 WARN，無豁免。

即時閱讀頁沿用相同 Framed sheet、青灰框架、IBM Plex Sans 與球場線條識別，未重新抽選風格。以「誰已晉級，我的下一輪對手是誰」為主要問題，將對戰圖作為首個檢視；勝方與已確定的晉級線使用青色，其餘連線與導覽保持中性。實線表示勝方晉級、虛線表示敗方進名次賽，連線來自實際來源場次而非推測配對。

桌機顯示多輪對戰，手機將圖表限制在可橫向捲動的區域，頁面本身不橫向溢出。日期與場地收在進階篩選，姓名、場號搜尋及組別始終可見。所有比分、完成數與狀態由公開快照計算，未決資格保留待確認；未填成績不顯示假比分。場號、時間與附註提高至 13px，減少圖表資料過小的問題。

獨立雙視窗驗收涵蓋成績預覽不更新、確認與更正後自動晉級、篩選與捲動保留、斷線恢復、還原工作區切換及替換靜態 JSON 來源，證據見 `output/lr-qa/`。三種寬度的實際截圖均已檢視；官方 taste-skill lint 與最終 inspect 為 0 FAIL／0 WARN，無豁免。測試採八位虛構正賽選手與一位候補，未修改真實名單或原操作工作區。使用及範圍見 [即時閱讀頁](live-reader.md)。

操作頁的八人虛構工作區及 147 筆原名單示範均已在 1440、768、390px 檢查。手機場次表轉成兩行資料列，登錄按鈕直接可見，選擇場次後進入編輯，再返回清單。IBM Plex Sans 已載入；實際中文字型由瀏覽器確認為 Microsoft JhengHei。官方 taste-skill lint 與 inspect（Node 20 使用 `--experimental-websocket`）均為 0 FAIL／0 WARN；無檢查豁免。截圖見 `output/operator-final-browser-qa/`，完整互動驗收見 `output/operator-browser-qa/report.json`，包含設定種子、主賽確認、四場首輪成績、種子敗者排除、三人鼓勵賽輪空、重新排程與匯出，無外部請求或 JavaScript 錯誤。

採用 [taste-skill](https://github.com/Leonxlnx/taste-skill) 的 app-screen 流程；此介面用於查場次與對戰，不採宣傳頁流程。

## 資料與使用情境

- 使用者：選手、家長及賽務人員，主要查詢姓名、對手、時間與場號。
- 收錄 230 筆原編號場次及 2 筆未編號表演賽，總數由資料列計算。
- 比賽日期為 2026-10-24、2026-10-25；不顯示即時或即將開賽的假狀態。
- 原稿未載球場仍保持未知，閱讀介面顯示破折號並保留原值提示。
- 姓名索引是原稿文字索引，不自動確認身分或兼報。
- 歷史圖現已涵蓋全部 25 原圖；新版閱讀前端顯示結構化重繪圖並保留來源核對。
- PDF、Excel 下載只在該輸出包確實有檔案時出現。
- 所有資料與字型均嵌入 HTML，離線直接開啟，不依賴 CDN。

## 設計方向

即時閱讀頁的循環賽增補可操作的 SVG 多角形圖，沿用現有字型、白底及青色資料標記。局數位於距離選手端點固定距離的線段上，以白色底框避開穿越的線條；五角圖的 20 個比分框逐一檢查不重疊。未完賽不填分，特殊判定用文字及虛線；手機圖內捲動、首次置中，更新保留位置。最新 9 張三種寬度圖形驗收截圖位於 `output/polygon-live-release/`，taste-skill 檢查位於 `../.taste-skill/polygon-inspect/`（0 FAIL、0 WARN）。

抽選方向：Framed sheet，seed `20261028`，kind `report`，screens `overview,list,detail`；無重抽。

主要問題：**我的場次何時開始、對手是誰？**

選擇的產品特徵：以壁球場線條作識別，採青灰色 L 形框架與白色工作區；時間欄使用單一青色，其他導覽維持中性。

專屬互動：兩個比賽日直接由真實場次統計成可切換的日程選擇；姓名、組別與日期查詢共用同一資料集。

字型：本機嵌入 IBM Plex Sans，中文使用 Microsoft JhengHei／PingFang TC 後備；數字採 tabular figures。來源與 OFL 授權位於 `src/squash_scheduler/assets/fonts/`。

總覽限制為 6 筆場次，再進入全部賽程；全部賽程每次載入 40 筆。手機將導覽與進階篩選收起，保持第一筆場次可在第一屏閱讀。

舊版、改版與匿名測試版分開保存；既有匯出包不覆寫。實測與截圖另存於本機輸出資料夾。

## 最終檢查與視覺評讀

官方 `inspect.mjs --app` 在 1440、768、390px 均為 0 FAIL、0 WARN；官方 `lint.mjs --app` 為 0 FAIL、0 WARN。已逐一檢視三種寬度的首屏與整頁截圖，並以 `file://` 實測兩份離線前端。字型檢查確認 IBM Plex Sans 已載入。

52 項前端／文件／匯出整合測試通過；最終前端回歸 7 項通過，涵蓋全文搜尋、40 筆分批載入、手機導覽、長名稱、注入防護、下載及離線載入。瀏覽器實測沒有 JavaScript 錯誤及外部 HTTP 請求。
