# 即時閱讀頁與晉級圖表待辦

記錄日期：2026-10-29（Asia/Taipei）

狀態：本機公開唯讀資料、可替換資料來源、即時晉級、循環積分與三階段驗收已完成；後續為雲端同步、部署及未定政策。使用方式見 [即時閱讀頁](live-reader.md) 與 [三階段成果](reader-standings.md)。

## 目標與目前狀態

目標流程：操作台確認並儲存成績 → 依既有規則計算晉級 → 即時閱讀頁自動更新比分、勝方與下一輪對戰圖。

目前 `/live/` 已連動操作台已儲存的賽事版本。已匯出的閱讀頁、SVG 與 PDF 繼續保存匯出當時的內容，供列印與留存。

## 已落實的兩項架構要求

| 要求 | 實作方式 | 驗證方式 |
|---|---|---|
| 公開資料與操作資料分離 | `public_feed.py` 明確投影為 `PublicSnapshot`；公開 API 使用 `/public/`，不轉送 `/api/state` | 測試操作者、原因、來源、內部路徑及備份不會出現在公開資料；讀取頁不帶操作 token，既有寫入仍受保護 |
| 資料來源可替換 | `HttpJsonSource` 與 `LiveReader` 分開處理資料傳輸及輪詢，畫面只消費同一份公開契約；`serve --reader-config` 可指定公開 JSON 來源 | 使用實際不同來源的靜態 JSON 伺服器，僅換設定，不修改閱讀頁或圖表，即可呈現相同賽況 |

公開契約見 [Schema](../schemas/public-snapshot.schema.json)。後續雲端同步須沿用此契約，先產生完整快照再更新版本描述；雲端上傳及部署尚未實作。

## 第一版範圍

- 先完成同一台電腦的操作台與即時閱讀頁雙視窗連動，沿用本機服務。
- 每 3 秒檢查賽事版本，有變更才更新內容，不要求使用者手動重新整理。
- 顯示目前工作區及版本、最後成功更新時間，保留搜尋、組別／日期／場地篩選與閱讀位置。
- 僅使用已確認儲存的成績；預覽、未確認輸入及尚未核准的抽籤不得發布為確定結果。
- 沿用既有晉級、成績更正、鼓勵賽資格及抽籤核准規則，需要人工裁定時顯示「待核定」。
- 區域網路、多裝置觀看及對外部署留待下一階段；第一版不變更目前服務僅綁定 `127.0.0.1` 的行為。

## 實作順序與驗收標準

| 順序 | 待做項目 | 工作內容 | 驗收標準 |
|---|---|---|---|
| 1 | 即時唯讀資料介面 | 提供目前賽事版本、已確認成績、晉級選手與場地狀態；僅輸出閱讀所需資料 | 可辨識工作區及版本；欄位來自一致的賽事快照；閱讀介面無修改功能，不暴露操作憑證、內部路徑或備份內容 |
| 2 | 即時閱讀頁 | 顯示對戰、比分、叫號、延誤與最後更新時間；定期檢查版本 | 成功儲存後，下一次成功更新取得新內容；自動更新保留搜尋及篩選，不重設閱讀位置 |
| 3 | 動態晉級圖表 | 顯示勝方及比分，將確定晉級者帶入下一輪；同步下一場對手、時間與場地 | 正常完賽確認後，不重新整理即可看到勝方進入下一輪；未決對手顯示「待確認」，不推測晉級 |
| 4 | 更正與例外處理 | 處理已核准成績更正、同分待裁定、棄權、輪空及鼓勵賽 | 合法更正同步更新圖表；既有領域規則拒絕的更正不影響閱讀頁；未核定排名或未核准鼓勵賽抽籤不顯示確定對戰 |
| 5 | 連線與版本提示 | 顯示更新狀態、斷線及過期提示；恢復連線後取得最新版本 | 斷線保留最後畫面並標示可能過期；恢復後同步最新資料；較舊回應不能覆蓋較新版本；工作區切換後清楚標示新來源 |
| 6 | 完整操作驗收 | 同時開啟操作台與閱讀頁，使用獨立虛構工作區驗證；檢查桌機與手機版面 | 通過登錄、更正、晉級、延誤、斷線恢復及版本切換流程；沒有水平溢出或 JavaScript 錯誤；留下報告與截圖 |

## 第一個可交付成果

在操作台確認一場比分後，另一個視窗不需重新整理，即可看到比分、勝方及下一輪選手更新。

淘汰賽、循環積分、人工排名裁定與鼓勵賽的已定義流程均已驗證；詳細範圍、原始名單與效能證據見 [三階段驗收說明](reader-standings.md)。人工裁定表單、未定規則及歷史正式核准沒有由本輪推定完成。

## 驗收情境

| 情境 | 預期呈現 |
|---|---|
| 僅輸入或預覽成績，尚未確認 | 閱讀頁保持最後已儲存內容 |
| 確認正常完賽 | 顯示比分與勝方，確定的下一輪位置改顯示選手姓名 |
| 合法更正勝方 | 比分、勝方及可更新的下游對戰同步更正 |
| 更正會影響已開打下游場次而遭拒絕 | 閱讀頁保留原先有效資料 |
| 同分仍待人工裁定 | 顯示待核定，不自行決定晉級 |
| 輪空、棄權或未到場 | 依既有規則顯示結果，不捏造比分或鼓勵賽資格 |
| 產生或確認鼓勵賽抽籤 | 僅在核准套用後顯示確定籤表；資格成立不等於自動抽籤 |
| 確認叫號、開賽或延誤 | 更新人工現場狀態，預定與實際開賽時間分列 |
| 網路中斷後恢復 | 先保留舊畫面並標示過期，連線恢復後更新 |
| 切換或還原工作區 | 明示目前資料來源，避免混用不同工作區的場次與版本 |
| 再次開啟已匯出的 PDF／離線閱讀頁 | 維持該次匯出內容，與即時頁各自標示版本及用途 |
